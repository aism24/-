# 斜め寸法の本数抽出(tdf-dim-count)
実寸法師(.tdf。14MB級のOLE複合ファイルの原本も可)から、**選択したレイヤ**の「斜めの数値テキスト」と、「同じ長さ・同じ角度の線」の本数を調べる静的アプリ。ブラウザ内で処理(サーバー不要)。
- 条件: レイヤ=選択、テキストは数値のみ、テキストと線は斜め(0°/90°から1°以内を除外)、長さ±0.5mm(または0.2%)、角度±1°。「逆向きの線も数える」で鏡像も対象。
- 仕組みは `core.js` 冒頭コメントと `docs/know-how.md` 参照。回帰テスト用の正解値: 原本のGEN=テキスト55個・線321本(5519が159本)。
- `vercel.json` で自動デプロイ停止。本番反映は「デプロイして」の指示時のみ `create_deployment`。
