# 製品別金物リスト(tdf-kanamono-list)

実寸法師(.tdf)の鉄骨詳細図から、製品ごとの金物(切板・形鋼)を拾い出して表示し、決めた様式のExcelに出す静的アプリ。
TDFの読み取り・拾い出し・Excel作成はすべてブラウザ内で行う。GASは工事リスト・サーバーの読み出しと利用記録だけ。
仕様(拾い出しルール・Excel様式・画面)は **`docs/apps/tdf-kanamono-list.md`**。

## 構成
```
tdf-kanamono-list/
  index.html / style.css  画面(見た目は tdf-master-web に合わせた)
  app.js        画面の動き(工場・工事の選択、取込、枚数・備考の修正、Excelダウンロード、記録の送信)
  extract.js    TDFの読み取りと拾い出し(ブラウザ・Node.js 両用)
  excel.js      Excelの様式(ExcelJS。工場ごとに様式を変えられる FORMATS)
  gas/Code.gs   スプレッドシート「製品別金物一覧アプリ」に貼るGAS
  assets/       ロゴ・実寸法師のアイコン(tdf-master-web と同じ)
  to-launcher.js「← アプリ一覧へ」(正本 docs/to-launcher/to-launcher.js のコピー)
  vercel.json   {"git":{"deploymentEnabled":false}}
```
Excelは ExcelJS 4.4.0(cdnjs)を、ダウンロードを押したときに読み込む。

## 使い方
1. 工場(本社・夢前・鳥取)を押し、工事番号・工事名をリストから選んで「開始」(ここで記録シートに日時・工事名・工場を記録)
2. 「① 本社サーバー」「① 鳥取サーバー」(設定シートE列のサーバーごとのボタン)のどちらかを押す。押した方は青、もう一方はリセットするまでグレーで押せない。最初の1回だけ、そのサーバーの「①進行中工事」を選んで覚えさせる(ブラウザに保存。フォルダの中はたどらない)。tottori-production-status から飛んだとき(工場は鳥取固定)だけは、本社・鳥取どちらのサーバーでも、押すたびに「①進行中工事」を毎回選ぶ(2026-11-20)。
   「② ファイル選択(何度でも可能)」(薄い緑)→ ①進行中工事から開くファイル選択の画面でTDFを選ぶ(複数可)。選んだファイルが ①進行中工事 から見てどこにあるか(FileSystemDirectoryHandle.resolve)を受け取り、
   設定シートF列のパスとつないでリンクにする(手入力しない)。①進行中工事 の外のファイルはリンクなし(お知らせを出す)。ドラッグ&ドロップも同じ(getAsFileSystemHandle)。
   ブラウザの決まり: フォルダ・ファイル選択の画面の id は英数字だけ(日本語を入れると画面が開かない。2026-11-19に「root-本社」で発生)
3. 除外したもの(スプライスPL・フィラーPL・吊りピース・ネット受けピース・サヤ管・現場付けの製品)があれば「〇〇は抽出していません」と出る
4. 枚数(本数)・備考を直す(直した枚数は赤くなる)。図面番号・製品名をクリックすると jissun:// で実寸法師が開く
5. 「📥 Excelダウンロード」。ファイル名は TDFが1つなら `<図面番号>_金物リスト.xlsx`、複数なら `<工事番号>_<年月日>_<時分>_金物リスト.xlsx`
   (ダウンロードしたら記録シートに1行と、同じ内容のデータシート「MMdd_追番」を追加。データシートは新しい10枚だけ残す)

## GASのセットアップ
1. スプレッドシート「製品別金物一覧アプリ」→ 拡張機能 → Apps Script に `gas/Code.gs` を貼り付けて保存
2. デプロイ → 新しいデプロイ → ウェブアプリ(次のユーザーとして実行=自分、アクセスできるユーザー=全員)
3. 表示された `/exec` のURLを `app.js` の `GAS_URL` に入れる(URLをチャットに貼ってもらえれば反映する)
4. `/exec` を開くと `{"status":"success","version":"…"}` が返る(`CODE_VERSION`)

## 確認(回帰テスト)
検証図面2枚(公開リポジトリのため図面は入れていない)で、拾い出しの結果を正解(仕様メモの「検証図面A・B」)と比べる。
`extract.js` を変えたら、ローカルの作業フォルダでテストを流してから反映する。
