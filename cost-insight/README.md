# コストインサイト(cost-insight)— 原価管理・生産進捗分析

「生産損益分析(production-profit)」と「実行予算まとめ(jikko-yosan)」を1本にまとめる新アプリ(開発中)。
完成後、旧2アプリ(GitHub・Vercel・スプレッドシート・GAS・.bat)は廃止する予定。

## 3つの単価(工事別・工場別・期間別)
- 1t当たり加工単価 = 契約金額 ÷ 契約総重量
- 1t当たり仕入単価 = 仕入(実行予算の 計 − 労務費3つ)÷ 契約総重量。期間・工場へは生産重量に比例して割り付ける。未完の工事は予算の値(「見込み」)
- 1時間当たり単価 = 労務費(工場労務費+事務図面労務費+現場労務費)÷ 工数
  - 工数は日報。共通の工数(共通扱い工事No・工事No不明)は同じ工場・期間内で工数比で按分して足す
  - 労務費は20日締め後に実行予算へ反映されるため、工事ごとに「労務費の締め」(実行予算Excelの月度列で労務費がある最後の月度)
    までの労務費 ÷ 同じ締めまでの工数 で計算する。締めより後の工数は直近の確定単価で見込む
- 生産重量・工数は生産管理・日報の実績を使う(実行予算Excelの加工重量・工数は使わない)
- 閲覧パスワードなし。グラフ・表、Excel・PDF(印刷)で出力

## データ
- スプレッドシート「コストインサイト」(会社フォルダ。シート: 工事マスタ・工事データ・基本設定・会社カレンダー)
- `gas/Code.gs`: スプレッドシートにコンテナバインド。第1段階は生産重量・工数の読み取りと集約(`_cache_production.json`)
- 開発中の確認URL: https://raw.githack.com/aism24/-/main/cost-insight/index.html
- `vercel.json` で自動デプロイを停止済み(公開時に create_deployment で反映)。

## GASの設置(第1段階)
1. スプレッドシート「コストインサイト」→ 拡張機能 → Apps Script。`gas/Code.gs` を全文貼り付けて保存。
2. エディタで `checkSetup` を実行して権限を承認(ログに件数が出ればOK)。続けて `setupTrigger` を実行(毎朝6時台の自動更新)。
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセス「全員」。発行URLを画面側に設定する。
