# コストインサイト(cost-insight)— 原価管理・生産進捗分析

「生産損益分析(production-profit)」と「実行予算まとめ(jikko-yosan)」を1本にまとめる新アプリ(開発中)。
完成後、旧2アプリ(GitHub・Vercel・スプレッドシート・GAS・.bat)は廃止する予定。

- 工事別・工場別・期間別に「1t当たり加工単価(契約金額÷契約総重量)」「1t当たり仕入単価(仕入÷契約総重量)」
  「1時間当たり単価(労務費÷工数+工場の月固定費÷総工数)」をグラフ・表で表示し、Excel・PDF(印刷)で出力する。
- 共通の工数(工事No不明分)は同じ工場・期間内で工数比で按分。仕入は生産重量に比例して期間へ割り付け。
  未完の工事は予算の値を使い「見込み」と表示。閲覧パスワードなし。
- 開発中の確認URL: https://raw.githack.com/aism24/-/main/cost-insight/index.html
- `vercel.json` で自動デプロイを停止済み(公開時に create_deployment で反映)。
