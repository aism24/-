コストインサイト 実行予算の更新 使い方

■ ふだんの使い方
  1. コストインサイトの画面で［実行予算を更新］を押す。
  2. 「Windows コマンド プロセッサ を開きますか？」などと聞かれたら［開く］を押す。
     (「常に許可」のチェックを入れておくと次回から聞かれません)
  3. 黒い画面に進み具合が出ます。数分かかることがあります。
     ・うまくいくと「送信先… 送信: 完了」と出て、15秒後に自動で閉じます。
     ・エラーは赤い文字で出て、画面は閉じずに止まります。内容を管理者に伝えてから、何かキーを押して閉じてください。
  4. 終わったら、コストインサイトの画面で［画面を再読み込み］を押す。
  ※このフォルダの 実行予算更新.bat をダブルクリックしても同じように動きます。

■ 初めて使うPC(1回だけ)
  このフォルダの costinsight登録.reg をダブルクリック →［はい］→［OK］。
  (そのPCのそのユーザーにだけ登録されます。管理者の権限はいりません)

■ 注意
  ・社内ネットワークに接続したPCでだけ動きます。
  ・ほかの人が更新しているときは「他の人が更新中です」と出て止まります。数分待ってからもう一度押してください。
  ・実行予算のExcelは読むだけで、書き換えたり開いたりはしません。
  ・このフォルダのファイル(pc フォルダ、設定.json、出力 フォルダを含む)は消したり動かしたりしないでください。
    場所を変えるときは costinsight登録.reg の中のパスも直して、各PCで登録し直す必要があります。

■ このフォルダの中身
  実行予算更新.bat      … 更新プログラムを動かす
  costinsight登録.reg   … ボタン(costinsight://)とこの .bat を結び付ける(各PCで1回)
  pc\update.js          … 更新プログラム本体(実行予算Excelを読み、コストインサイトと旧 実行予算まとめ へ送る)
  pc\設定.json          … 読み取り元フォルダ・送信先・秘密キー
  pc\node.exe・node_modules … プログラムを動かす部品(各PCに Node を入れなくてよい)
  pc\出力               … 前回の結果(data.json)と実行ログ.txt。全員で共有する
