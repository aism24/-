# 大組図から短管リスト作成(jissun-tankan-list)

実寸法師の大組図(.tdf)から、コラム(角形鋼管)柱の「短管リスト」Excelを作る Web アプリ。
前身はローカルの Python 版(社内の共有フォルダ。大組図の読み取り・板の外形の測り方・重量の決まりは同じ)。
2026-11-25 作成。抽出・照合・Excel の決まりはローカル版と同じで、26-12 の2節(大組図55ファイル)で結果がローカル版と一致することを確認した。

## 構成
```
jissun-tankan-list/
  index.html / style.css  画面(見た目は tdf-kanamono-list と同じ)
  app.js        画面の動き(工場・工事の選択、サーバーの「①進行中工事」、TDF の選択、表示、Excel ダウンロード、記録)
  excel.js      Excel 作成(ExcelJS 4.4.0。ひな形の表を写して値・式・絵・リンクを入れる。Node.js でも動く=試験用)
  py/tankan_core.py  大組図の読み取り・板の外形・手配書との照合・板の線画(Pyodide で動かす。PC の Python でも動く)
  py/plate.py   板の外形の測り方と線画(ローカル版と同じ。SVG を文字で返すようにしただけ)
  py/tdf_binary.py   TDF の読み込み(tdf-master-web/scripts/tdf_binary.py と同じ)
  template/tankan-template.xlsx  Excel のひな形
  gas/Code.gs   スプレッドシート「短管リスト」に貼る GAS
  assets/ to-launcher.js vercel.json
```

## 使い方
1. 工場(本社・夢前・鳥取)と工事を選んで「開始」(記録シートに日時・工場)
2. 「① 本社サーバー」「① 鳥取サーバー」… 最初の1回だけ、そのサーバーの「①進行中工事」を選んで覚えさせる(tdf-kanamono-list と同じ)
3. 「② 大組図のTDFを選ぶ」… 1つの節の大組図(立面図 2C-01… と A付きの断面図 2C-01A…)をまとめて選ぶ。ドロップも可
   - 注文書(切板手配書)は GAS がドライブ「切板CSV工事別まとめ」の `<工事番号>.csv` を返す。PC の「切板CSVキャッシュ作成.bat」で更新する
   - 図面の読み取りは Pyodide(初回は Python の準備に数秒)。55ファイルで約2分
   - 読めなかった図面・BH柱(除外)・手配書と合わない板はお知らせに出す
4. 表で確かめる(階ごと、柱の表ごと。図面番号を押すと jissun:// で実寸法師が開く)
5. 「Excelダウンロード」… `短管リスト_<工事番号>_<節>_<日時>.xlsx`。記録シートに1行と、同じ内容のシート「MMdd_追番」

## 決まり(ローカル版と同じ)
- 柱の表のまとめ方: 階ごとに、サイズ・長さ・板・仕上がりがまったく同じ柱を1つの表にまとめる(提出済み Excel のまとめ方と3つの階とも一致)。表の並びは図番の順(提出済み Excel は手で並べた順なので同じにならない)
- サイズ1つの柱は表A、サイズが2つ以上(テーパー)の柱は表B。板マークは板の行9行に上から置く(2枚=1・9行目、4枚=1・3・7・9行目)
- 重量: 短管=単重×コラム長さ(テーパーは中間サイズの単重。単重表はひな形の板シート)、板=手配書と照合して合えばグロス、合わなければ図面から計算した値で黄色。小数第2位は Python の round と同じ丸め
- 短管の絵(D〜M列)と PL形状注意(縦≠横の板。R・T列)の絵は画像で貼る。PL形状注意の並びはローカル版と同じ
- V列=図面番号・W列=A付き図面番号・X列=製品名に大組図 TDF へのリンク(柱符号1つにつき1行)
- 改ページ: 1ページ58行まで(表の途中では切らない)
- 未決(空欄のまま): 材質(D列)・シーム方向・ダイア出寸法・板ごとの「←ダイア出寸法」の注記。工事名は情報シートの工事名(発注者は付けない)

## 確認のしかた
- `py/tankan_core.py` を変えたら、PC の Python でローカル版の結果(ok2.json・check.json・verify.json・order_rows.json・板の絵)と比べる(大組図は公開リポジトリに入れない)
- `excel.js` を変えたら、Node.js(exceljs 4.4.0)で Excel を作り、ローカル版の Excel と柱・階ごとに比べる

## ひな形(template/tankan-template.xlsx)
- 「階」シート: 1〜2行目=見出し、3〜16行目=表A(サイズ1つの柱)、17〜32行目=表B(テーパーのある柱)。印刷範囲 B:U、V〜X列はリンク用(印刷範囲の外)。
- 「板」シート: 一般的な角形鋼管の単重表(A:B)だけ。アプリが手配書の行を足す。
- 「説明」シート: 置き換え文字の一覧。
- 提出済みの Excel から書式と表の形だけを取り出して作った(実データ・作成者情報は入れていない)。

## GAS(gas/Code.gs)とスプレッドシート
管理用スプレッドシート「短管リスト」にバインド(拡張機能 → Apps Script に貼る)。他のアプリとは共用しない。
1. `gas/Code.gs` を貼って保存し、関数 `checkSetup` を1回実行(情報・記録シートと注文書フォルダの確認。ドライブの権限の承認もここで出る)
2. デプロイ → ウェブアプリ(実行=自分、アクセス=全員)。`/exec` で `CODE_VERSION` が返る
- 情報: A=工事番号 B=工事名 / E=サーバー F=ファイルパス(1行目は見出し)。`?action=settings`
- 注文書: `?action=orders&koji=26-12` … ドライブ「切板CSV工事別まとめ」の `<工事番号>.csv`(UTF-8)と更新日時。無ければ csv は空。フォルダ ID は Code.gs に書いてある(ユーザー了承)
- 記録: A=日時 B=工場 C=シート名、新しい行は2行目。開始(POST `start`)で日時・工場、Excel ダウンロード(POST `download`)で日時・工場・シート名
- データシート「MMdd_追番」: ダウンロードした Excel と同じ内容。新しい10枚だけ残す。記録は画面に出さない(金物リストと同じ方式)
