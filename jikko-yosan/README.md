# 実行予算まとめ(jikko-yosan)

各工事の「実行予算」Excel(最新シート)の契約総重量・契約金額・9費目の予算/実際/割合・粗利益/営業損益の予算/実際(データ上の項目名は「営業利益」)を一覧表示し、
前回(前日までの最後の値)から変わったセルを黄色で示す。Excelダウンロード付き。

## 構成
- 会社PC: `実行予算更新.bat`(pc/update.js)が毎朝、数値だけをGASへPOST(`{secret, data}`、text/plain)。
- `gas/Code.gs`: 受信(秘密キー照合)・保存・画面へのJSON返却。保存先は会社フォルダ(実行予算まとめアプリ用)の
  `実行予算まとめデータ.json`。前日以前の値を「比較の基準」に繰り上げる。原価データはGitHubに置かない。
- 工事単価シートへの反映: 受信のたびに、生産損益分析アプリの「損益分岐点生産重量」→「工事単価」のA〜D列
  (工事No・工事名・契約総重量・契約金額)を工事No単位で上書き(実行予算を正)、無い工事Noは末尾に追加。E列以降は触らない。
  元ファイルなし・読み取りエラー・一覧に未登録・重量と金額がどちらも0の工事は対象外。
- 画面: `index.html` / `app.js` / `logic.js`(変更判定・Excel書き出し) / `style.css`。`?demo=1` でダミーデータ表示。

## GASの設置
1. https://script.google.com で新しいプロジェクトを作り、`gas/Code.gs` を貼り付けて保存。
2. プロジェクトの設定 → スクリプトプロパティに `SECRET`(秘密キー)を追加。
3. エディタで `checkSetup` を実行して権限を承認(ログに保存先フォルダ名と「工事単価シート: あり」が出ればOK)。
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセス「全員」。
5. 発行されたURLを `app.js` の `GAS_API_URL` と、PC側 `設定.json` の「送信先URL」に、秘密キーを「秘密キー」に記入。
