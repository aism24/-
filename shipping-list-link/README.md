# 出荷リスト 図番リンク付与アプリ

PDFを入れると、(図番, 製品名)がマスタと完全一致した行の**製品名**にハイパーリンク(`file://…tdf`)を付けてダウンロードする。
静的サイト(ビルド不要)+ GAS。`vercel.json` で自動デプロイは停止済み(公開は「デプロイして」の指示時のみ)。

- `index.html` / `app.js` / `core.js` … 画面と照合処理(ブラウザ内)。`vendor/` は pdf.js・pdf-lib(同梱)
- `xlsx-link.js` … Excel(.xlsx/.xlsm)版の照合・リンク付与。`vendor/jszip.min.js`(同梱)でXMLを直接書き換える
- `gas/Code.gs` … ms-tottori アカウントのGAS(下記手順)
- マスタは `app.js` の `GAS_URL`(必須)から取得する。動作確認用のサンプル(`sample/links.json`)は実データを含むため2026-10-21に削除(公開リポジトリ)

## GASセットアップ
1. Apps Scriptに `gas/Code.gs` を貼り付け
2. `setupDaily` を1回実行(毎朝6時にリンク表を更新)→ 権限承認
3. `buildMaster` を1回実行(リンク表 `_リンク表.json` が保存フォルダに作られる)
4. デプロイ → ウェブアプリ(実行=自分 / アクセス=全員)→ URLを `app.js` の `GAS_URL` に設定
   (コード更新時は「デプロイを管理」→ 鉛筆 → 新バージョン、でURLを変えずに反映)

## 動作仕様
- 1件以上リンク付与: ダウンロード →「ダウンロードしました / リンク付与できた図番○件 / 付与できなかった図番○件」のポップアップ
- 0件: ダウンロードせず「リンクが付与できず、ダウンロードしていません / マスタには無い図番と製品名の可能性あり」
- どちらも「OK」でアプリをリセット(初期状態に戻る)
- 画面のどこにドロップしても受け付ける
- 元PDFの保存+シート「記録」の2行目へ挿入(列: 日時 / 枚数 / PDFのURL / リンク付与 / NG)。0件のときも記録する
- 加工予定表(その他PDF)対応: 「加工予定表」のあるPDFはそのページだけを、列単位(製品名・台数・重量・図番)で照合する。回転ページも可。
- リンクが付いた製品名は青い下線のみ(文字色・背景は変えない)
- NG = 図番らしい(マスタの図番と同じ形の)語がある行のうち、リンクが付かなかった行数(加工予定表は列単位)。マスタに複数リンクがある「重複」もNGに数える

## マスタの更新と「最新のリンク付きマスタを取得」ボタン
- リンク表JSON(`_リンク表.json`)の更新は、毎朝6時台の自動実行(GASは6:00〜7:00の間のどこか)と、ボタンの2つだけ。アプリを開いただけでは更新されない
- ボタン: GASが「マスタExcel→リンク表JSON」を今すぐ作り直し(`?action=rebuild`)、画面のマスタを読み直す。応答が取れないときは `?action=info` で完了を待つ(最大約2分)
- マスタExcelの「名前+更新日時」が前回の再生成時と同じなら再生成を省く(約30秒→約2秒)。変更があったときは、**前回の再生成後に更新されたExcelだけ**を読み直し、ほかは保存フォルダの `_リンク表_Excel別.json`(Excelごとの抜き出し結果)を使う(2026-10-23〜)。毎朝の自動実行は全件読み直す
- 再生成のたびにGAS側キャッシュを新しいリンク表で作り直す(消すだけにしない)。GASのログに、読み直したExcelと所要時間が出る。`?action=ping` で GAS の版(`CODE_VERSION`)を確認できる
- 連打は1分で制限(1分以内は「更新済み」)、同時実行はロックで防止
- 安全弁: 新しい件数が旧の90%未満なら上書きしない(毎朝の自動実行にも適用)。正当に減ったときだけApps Scriptで `buildMasterForce` を手動実行
- 画面に「更新(日本時間)」と「Excel最終更新」を表示。更新後は日時が一瞬光る
- 反映されるのはDrive上のExcelの内容。PCで編集してDriveへの同期前なら反映されない

## アプリを開いたときのマスタ(2026-10-23〜)
- 取得したリンク表は、そのPCのブラウザ(IndexedDB)に保存する。次に開いたときは保存分をすぐ表示してポップアップを閉じ、裏で `?action=info` の更新日時と比べる
- 同じなら「このPCの保存分…・最新を確認済み」。違えば `api/links?v=<更新日時>` で取り直して差し替え・保存(「新しいマスタに更新」、更新日時が光る)。版ごとにCDNに残るので2台目以降は速い
- そのPCで初めて開くとき・保存が使えないとき(シークレットウィンドウ等)は従来どおり中継API→GAS直接で取得。ボタンで取得したリンク表も保存する

## NG一覧
結果ポップアップの「NG一覧を見る」で、頁・図番・製品名・理由(マスタに無い図番 / 製品名が不一致 / 重複)の表を開閉できる。

## リンク形式(2026-10-05 実機検証済み)
`app.js` の `LINK_MODE` で切り替え(戻したいときはここだけ変更)。
- `'web'`: PDFのリンク = `https://shipping-list-link.vercel.app/open.html?p=<社内パス>`。`open.html` が `jissun://` へ転送して実寸法師を起動。
  Acrobatは通常のWebリンクとして扱うので「PDFファイルを起動しようとしています」の警告が出ない(「サイトに接続」の警告は初回に許可+記憶)。
  `open.html` は社内IP(192.168.x.x 等)の `.tdf` だけ許可。
- `'file'`(既定): マスタの `file://…tdf` をそのまま埋め込む。Acrobatの警告が2回出る。`'web'` は操作が1工程増えるため、2026-10-05に既定を `'file'` へ戻した。
- 検証結果: `file:////`・起動型(Launch)は警告が消えず/開けない。Acrobatは `jissun://` を直接は起動しない(Webページ経由が必要)。Edgeでは `jissun://…tdf` で実寸法師が開くことを確認。

- Excel対応(2026-10-27): .xlsx/.xlsm も同じ画面に入れられる。様式は固定せず、全シート・全セルを対象に「同じ行にある図番セルと製品名セル」を照合する。1行に複数セットがあるときは列が近い図番と製品名を組にする(使ったセルは再利用しない)。全角半角・前後空白の違いはそろえて比較。製品名セルにハイパーリンクを付け、元の書式に青い下線だけ足す。既存の同セルのリンクは置き換える。出力は `<元の名前>_リンク付き.xlsx`。NG一覧の場所は「シート!行」。重複(マスタに複数リンク)は付けずNG。図番と製品名が別の行・.xls(旧形式)・1セルに両方入っている様式は未対応。元のExcelはGASへ保存・記録しない(PDFのみ記録)
