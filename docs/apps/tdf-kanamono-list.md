# 金物リストアプリ(tdf-kanamono-list)の仕様メモ(検討中・未実装)

TDF(実寸法師)の鉄骨図面から、製品ごとの金物(切板・山形鋼)リストを作り、Excelで出すアプリ。
2026-11-19にユーザーと様式・拾い出しルールを決めた(アプリ本体はまだ作らない指示)。フォルダ名は `tdf-kanamono-list/`(2026-11-19決定。未作成)。
公開リポジトリのため、工事名・工事番号・実図面はここに書かない(検証図面は「検証図面A」と呼ぶ)。

## 予定の構成・機能(ユーザーの要件)
- GAS → GitHub → Vercel(管理用のDriveフォルダ・スプレッドシートはユーザー作成済み。IDはここに書かない)
- ① アプリ起動 ② サーバー(TDFの置き場所)を指定=Excelのハイパーリンク用 ③ TDF取込(別フォルダからも追加可。ただし同じ工事だけ)
- ④ 金物リスト一覧をテーブル表示。図番クリックでPowerShell経由で実寸法師を開く ⑤ ハイパーリンク付きExcelダウンロード
- **除外したもの(下の「対象外」)は、アプリでは「除外一覧」として表示する**(黙って捨てない)

## 画面の仕様(2026-11-19決定分)
- 見た目は **tdf-master-web に寄せる**。ヘッダーの会社ロゴ・会社名はいつも通り(tdf-master-webと同じ)。「← アプリ一覧へ」(共通 to-launcher.js)。
- **工事の選択**: スプレッドシートの工事番号・工事名のリストから選ぶ。選んだ工事番号はブラウザに記憶し、次回は自動で選ぶ。
- **利用記録**: 起動では記録しない。**工事をリストから選んだときに記録する**(利用者に分からないように。`docs/know-how/usage-log-hidden-check.md`)。
- **同じ工事の判定**: 図面(TDF)の表題欄の**工事名**で比べる。違う工事のTDFは取り込まない。
- **図番クリック**: `jissun://` のような独自リンク + パソコン側のPowerShellの設定で実寸法師を開く(jissun-open と同じ仕組み)。
- **枚数の修正**: 自動で拾った枚数を、人が画面で直してからExcelに出す。
- **除外項目はExcelに出さない**。取込のときに除外したものがあれば、取込後にポップアップで「〇〇は抽出していません」と出し、OKボタンで閉じる。〇〇は**除外の種類だけ**(例「吊りピース・ネット受けピースは抽出していません」。製品名・数は出さない)。
  除外の対象(2026-11-19時点): スプライスPL・フィラーPL・吊りピース・ネット受けピース・現場付けの製品。
- **サーバー(TDFの置き場所)の指定**: tdf-master-web の「📁 フォルダを選ぶ」と同じ方法。
- **管理用スプレッドシート「製品別金物一覧アプリ」**(Driveのフォルダは `docs/drive-folders.md`。IDはここに書かない):
  - シート「設定」: A列=工事番号、B列=工事名(1行目は見出し)。画面の工事リストはここから読む。
  - 同じシート「設定」のE列=サーバー名(例 本社・鳥取)、F列=ファイルパス(各サーバーの「①進行中工事」フォルダの絶対パス)。工事の行とは独立した表。サーバーのIPアドレス・パスはここに書かない。
  - 画面: tdf-master-web と同じく「図面があるサーバーを選んでください」でE列から選ぶ → F列のパスを基準に「📁 フォルダを選ぶ」で選んだフォルダの絶対パスを組み立て、Excelのハイパーリンクと図番クリック(jissun://)に使う。
  - シート「記録」: 利用記録。工事をリストから選んだときに1行: A列=日時、B列=工事名(設定シートの工事名=略称)。起動時・Excelダウンロード時は記録しない。
  - 注意: 設定シートの工事名は略称(例「LP北伊丹」)で、図面の表題欄の工事名(正式名)とは一致しない。Excelの工事名は図面から読む。


- 対象: 切板(PL・GPL・FB)と、セパ溶接固定用下地などの山形鋼(L-)。本体の鋼材(H・SH・BTの本体)は載せない。
- **対象外(除外一覧へ)**: スプライスPL・フィラーPL・吊りピース・ネット受けピース・**現場付けの製品**(例: 梁の両端に現場で付けるBT)。
- 同じ形の板は、文字が1か所だけでも**図形の数で数える**(例: FB-6x65x255 は継手の片端に上下2枚=1台4枚。文字は上側だけ)。
- 山形鋼は断面図のとおり片側(両側と書かれていなければ片側)。長さは立面図の線を1本ずつ測る(寸法の文字と一致を確認)。
- 工場で付く部材は、その製品で拾う(例: 大梁の上のBT-340は工場で付くので大梁で拾う。現場付けのBTは除外)。
- スチフナーは断面図のとおり両側。ただし**反対側にガセット(GPL)が来る位置(B断面のような小梁の取合い)は、スチフナーは片側**。
- 吊りピースの見分け方: 上フランジ下の300×230程度の箱(吊りピース(KG1A)などの記載の位置)。除外一覧へ。
- ネット受けピースの見分け方: 下フランジに並ぶ小さな部材(寸法列の位置に描かれ、「K8(両側)」の記載があるもの)。レイヤ「ネット受けピース」もある。除外一覧へ。
- 枚数(本数) = 1台あたり × 台数。
- 参考(除外になったが判断の知見): フィラーの「内」はウェブの両側で2枚。

## Excel様式(決定)
- ファイル名: `<図面番号>_金物リスト.xlsx`(図面番号は図面の表題欄に書かれたもの。例 `B1M2G-001_金物リスト.xlsx`。TDFのファイル名ではない)
- TDFを複数取り込んだときは**1つのExcelにまとめ**、**総まとめは取り込んだ全TDFの合計**
  - ファイル名: `<工事番号>_<年月日>_<時分>_金物リスト.xlsx`(例 `26-17_20261119_1530_金物リスト.xlsx`。日時はダウンロードした時刻)。TDFが1つなら `<図面番号>_金物リスト.xlsx`
  - 総まとめの見出し: 「取り込んだTDF全ての総まとめ」
  - 製品の並び順: 図面番号順に並べ替え、同じ図面の中は製品名の昇順。**番号は数として比べる**(GJ9→GJ10→GJ12。文字の順だとGJ10がGJ9より前になるため)
- 製品の「サイズ」は本体の主材だけ(例: BT-340が載る大梁でも SH-700x300x14x22 だけ書く)
- シート「金物リスト」1枚。A〜D列 幅20.625、E列 幅9。フォント ＭＳ Ｐゴシック。
- 1行目: 「金物リスト」(14pt太字、下罫線細) / 2行目: 工事番号(太字) / 3行目: 工事名(図面から読む。B:Dを結合) / 4行目: 空き。
- 製品ごとのブロック(製品の番号順):
  1. 「図面番号|製品名|サイズ|長さ（mm）|台数」(薄黄 FFFFCC、外周の左右と上は二重線)
  2. その値の行(薄黄、下は太線)。サイズ・長さは本体の鋼材。**行の高さは倍(28.5)・縦方向は中央揃え。ハイパーリンクは**図面番号と製品名の両方のセル**に付け、青(0000FF)太字・下線**
  3. 「サイズ|切板名（長さ）|枚数（本数）|備考」(水色 DDEBF7・太字)
  4. 明細(罫線細、左右の外周は二重線)。符号がある板は「GPL-9|KG1」、寸法で書かれた板は「FB-6x65|255」、山形鋼は「L-50x50x6|長さ」。備考は例「デッキ受け」「セパ溶接固定用下地」
  5. 小計(灰 F2F2F2・太字、下は二重線。板と山形鋼は分けずに合算) → 空行(高さ15)
- 最下部: 「総まとめ（<図番> 全製品）」(12pt太字) → 見出し(水色) → 全製品の合算(黄 FFF2CC。**板厚の小さい順**(FB-6→9→12→16)、同じ板厚はサイズの文字順(GPL→PL)→符号/長さ順。山形鋼は最後に長さ順) → 合計(灰)。
- 行の高さ: 1行目17.25、製品の値の行28.5、ブロックの見出し・一覧見出し・小計・総まとめ見出し14.25、空行15(総まとめの直前だけ14.25)、ほかは既定13.5。
- 印刷: A4縦・横1ページに収める(縮小96%)、上下余白2.5cm・左右1.9cm、1〜4行目を毎ページ印刷。
  **各ページの先頭は必ず製品名のブロックか総まとめ。ブロックの途中で改ページしない**(ブロック単位で収まらなければ直前の空行の後で改ページ)。
- 見本は検証図面Aで作成し、ユーザーの書式ファイルとセル単位で照合済み(ローカルの作業ファイル。リポジトリには入れていない)。
