# truck-fax(車番連絡FAX取込)のルール


- **PDFで取り込んだ行は、取込一覧に必ず残す。行の削除はしない(GASにも削除の窓口は無い)。**(2026-10-21、ユーザー指示で変更: 「FAX内容が間違っていた」ときに後で直すため、**取込一覧の画面で行をクリックして内容を編集することは可**。GASの `updateImport` が、編集できる項目だけを、変更前の値と照合して書き換える。ファイル名・タイムスタンプは直せない。以前は「内容の上書きもしない」だった。) 変更=元の記録の「追加変更」を「変更前」にし、今回の内容を「変更後」の行として追加。取消=元の記録の「追加変更」を「中止」にする。台数追加は、新しい行を追加し「追加変更」は空欄。車両台数は、「追加変更」が「中止」「変更前」**以外**の行を数える。
- **車種の大文字「T」は小文字「t」にそろえて記録する**(全角も。取込一覧・車両・運転手情報)。現場名(工事名)は対象外(英字を含む名前を変えないため)。
- **手配業者は、FAXの発信元から、候補(情報シートの見出し「手配業者」の列。既定: ナミツー・大上)の名前で記録する。** 運送業者・手配業者の書き方の違いは同じ会社とみなして照合する。車と運転手の組み合わせが「車両・運転手情報」に既にあれば追記しない(2度目の運行)。無ければ、同じ車に別の運転手・同じ運転手が別の車でも、別の行として自動で追加する(2026-10-22。車が登録済みでも、新しい運転手は確認なしで登録する。「登録しない」「今回だけこの値」を選んだ行は追加しない)。
- **同じ車・同じ運転手を、別の手配業者(大上⇔ナミツー)も手配したとき**(運送業者・車種・車番・氏名・携帯番号は同じで、手配業者だけが違う): 行は増やさず、その行の**備考に「大上/ナミツー」(大上が先)と書く**。この場合だけ、備考を**赤太文字**で表示する(2026-10-22、ユーザー指示)。
- **同じ運転手が、車種の違う車に乗る**(車両・運転手情報に、車種違いの行が2つ以上): どの行の備考にも「10t/高TR」の形で車種を書く(GASが自動記入。2026-10-22、ユーザー指示)。同じ車番・同じ運転手でも、車種が違えば別の行にする。運送業者のかっこ書きは取り除いて記録する(株・有などは残す)。
- **備考はアプリで入力する。** FAXの備考欄・特記・荷種などの文字と連絡文は、備考の初期値に入れる(記録前に直せる)。積地は記録しない。
- Geminiのモデル名・APIキーは情報シートのセルから読む(上の「共通指示」の例外)。履歴用のシートは作らない。
- 実際のFAXの画像・氏名・電話番号は、リポジトリに入れない(公開リポジトリ)。テストは作業後に削除する。
- 仕様の詳細は `truck-fax/README.md` と、Driveの引き継ぎ書(上の表)。
