# 鳥取梁ロボ管理(tottori-robot)

梁溶接ロボ(1号機・2号機)の稼動実績を工事マスターと突き合わせ、指定期間の状況をまとめて
Excelでダウンロードする静的アプリ(画面=静的ページ + GAS JSON API)。
実寸法師はアプリ内では開かず、ダウンロードしたExcelの図面番号リンクからローカルで開く。

## 構成
- `index.html` / `style.css` / `app.js` … 画面・集計・Excel作成(ExcelJSをCDNから読込)
- `gas/Code.gs` … 「鳥取梁ロボ管理データ」にバインドするGAS(JSON API)
- `sample.json` … GAS未設定時に表示するダミーデータ(実データではない)
- `vercel.json` … Git連携しても自動デプロイしない設定(公開は create_deployment で行う)

## データの流れ
- 「各種情報」シート: A〜E=工事別マスター一覧 / G〜H=1号機・2号機の稼動実績ID / P〜Q=工事名 / S〜T=カレンダー / V〜W=工事名称の別名表(アプリが追記)。
- ロボの「工事名称」「柱番号」は手入力。工事名称は別名表→ファイル名/工事名の部分一致で工事を判定し、柱番号=製品マークでマスターと突き合わせる。
- 工事が判定できない行は集計から除外し、画面で工事を選んで別名登録できる。
- 製品マークがマスターに無い行は黄色(候補あり。ボタンで修正)/赤(候補なし)。修正はブラウザ内の上書きで、ロボ側データは変更しない。
- カレンダー(S列)の最初の日より前のデータは集計しない。
- 1つの製品を複数回溶接した記録は、ロボ×製品の1行にまとめて「溶接回数」を表示する。

## 集計の定義
- 経過時間=「運転時間(ワーク)」、アークタイム/ワイヤ/換算溶接長=各「(ワーク)」列(「運転前」列は足さない)。非アーク=経過−アーク。
- 重量(t)=マスターの重量を「ロボ×製品」ごとに1回だけ加算(最初の溶接の月)。
- 月の区切り: 一般の月 / 20日〆(前月21日〜当月20日)を画面で切替。開始日の月で集計。
- 費用=稼動時間(h)×単価(初期4,000円/h。参考PDFの数値から推定。画面で変更可)。

## 読み取り専用の原則
稼動実績・マスターExcelには書き込まない。マスターExcelは同フォルダの作業用コピーに変換して読む。
書き込むのは作業用コピー/キャッシュJSONと、「各種情報」V:W列(別名表)のみ。

## セットアップ
1. 「鳥取梁ロボ管理データ」→拡張機能→Apps Script に `gas/Code.gs` を貼り付け、サービスに「Drive API」を追加。
2. `checkSetup` を実行して構成を確認 → `createDailyTrigger` を実行(毎日5時にマスター更新)。
3. 「デプロイ→新しいデプロイ→ウェブアプリ(自分として実行/全員)」のURLを `app.js` の `GAS_API_URL` に設定。
