# TSBL大会運営（７チームVer）：GAS × GitHub Pages 分離構成

7チーム・2日間のスイス7風トーナメントを、**複数の大会を名前で作成しながら**運営できるアプリです。
`taikai-unei/`（24チーム版バスケ大会アプリ）と同じ構成（**GitHub Pagesでフロントエンド配信 + Google Apps ScriptでJSON API + スプレッドシートをデータストア**）を採用しています。

## アプリの挙動

1. 大会名をテキスト入力（略称欄に頭2文字が自動入力されるが、最大4文字まで編集可能）
2. 略称で「〇〇＿１日目」「〇〇２日目」のシートを自動作成
3. 参加チーム（7チーム）を登録
4. 1日目の結果（得点）を記録 → 自動で順位確定
   - 得点はテキスト入力ではなく、百の位（0・1）・十の位・一の位（各0〜9）をボタンで選ぶ
     「□□□-□□□」形式（例: 042-105）で入力します（0〜199点まで）。
   - 試合は1試合目から順番にしか新規入力できません（前の試合が未記入だと次は入力不可）。
   - 記録済みの試合は「再編集」ボタンで後から修正できます。
5. 1日目が完了次第、「2日目作成」ボタンで2日目の対戦カードを自動生成
   （1日目の対戦相手とは別の相手・近い順位同士を優先する既存ロジックを踏襲）
6. 2日目の結果（得点）を記録（1日目と同様、順番入力＋再編集に対応）

各ステップの途中経過を含め、いつでも現時点の結果をPDFでダウンロードできます。
大会名・対戦結果（勝ったチームをアプリ画面と同じ色でハイライト）・TO/審判・順位表
（勝数・得点・失点・得失点つき）まで全てを1枚に大きく中央揃えでまとめた専用レイアウトで出力します
（PDFはDriveに保存せず、その場でアプリに直接渡す方式のため、Driveへの権限は不要です）。
順位表は、1試合も結果が入っていない（大会開始前の）状態では出力されません。
また勝数・得失点の両方が同じチームは同順位として扱います（行の並び順などでの無理な差はつけません）。

## 構成

```
swiss7-tournament/
  index.html   … フロントエンドのHTML（画面構造のみ）
  style.css    … スタイル
  app.js       … 画面ロジック + GAS APIとの通信処理（fetchでGET/POST）
  gas/Code.gs  … GAS側に貼り付けるバックエンドコード（JSON専用API）
```

## 1. 準備：スプレッドシート側

このアプリは、テンプレートシート **「１日目」「２日目」** を持つスプレッドシートに紐づけて使います
（`00_Claude最初に読む_引継ぎ書.txt` にある「6789」スプレッドシートと同じレイアウト：
B2:B8=チーム名、C12:C18・E12:E18=得点入力、K2:K8=順位（数式で自動計算））。

大会を1件作成するたびに、この2枚のシートをコピーして
「(略称)＿１日目」「(略称)２日目」を作ります。略称は大会名の頭2文字が自動入力されますが、
作成フォームで最大4文字まで自由に編集できます（大会名のフルネームは別途保存され、大会を開くと表示されます）。
**テンプレート自体（「１日目」「２日目」の2シート）は空の状態のまま残しておいてください**
（削除すると新しい大会が作れなくなります）。

同じ略称の大会を2つ作ることはできません（衝突した場合はエラーになります）。

## 2. GAS側（バックエンドAPI）のセットアップ

1. テンプレートのスプレッドシートを開き「拡張機能」→「Apps Script」を開きます。
2. `gas/Code.gs` の内容を、Apps Scriptエディタの `Code.gs` にまるごと貼り付けます。
3. 保存後、右上の **「デプロイ」→「新しいデプロイ」** を選択します。
4. 歯車アイコンから種類を **「ウェブアプリ」** に設定し、以下を指定します。
   - **次のユーザーとして実行**: 「自分」
   - **アクセスできるユーザー**: **「全員」**（フロントエンドから匿名でアクセスするため必須）
5. 「デプロイ」をクリックし、表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxxx/exec`）をコピーします。
6. 初回デプロイ時にGoogleアカウントの承認画面が出るので、権限（スプレッドシートへのアクセス・外部URLの取得）を許可してください。
   PDFはDriveに保存せず直接返す方式のため、**Driveへのアクセス許可は不要**です。
7. **このURLをClaudeとのチャットに貼り付けてください。** `app.js` の `GAS_API_URL` に反映してGitHubにpushします。
8. コードを修正した場合は、この既存デプロイを「編集」して「新バージョン」として更新すれば、URLは変わりません
   （常に同じURLで最新版が動くようにするため、新規デプロイは作らずこの方法で更新してください）。

### 注意点

- GASのウェブアプリはCORSのプリフライトに対応していないため、POSTは `Content-Type: text/plain` で送信しています。
- レスポンスは常にHTTP 200で返り、成否は返却JSONの `status` フィールドで判定します。
- 完全無料で運用できる構成です（GAS・スプレッドシート・GitHub Pagesはいずれも無料の範囲内）。

## 3. フロントエンド（GitHub Pages）のセットアップ

1. `swiss7-tournament/app.js` の先頭にある `GAS_API_URL` を、手順2で取得したURLに書き換えます（Claudeが担当）。
2. 変更をリポジトリにコミット・プッシュし、mainブランチに反映します。
3. GitHubリポジトリの **Settings → Pages** を開き、`Deploy from a branch` / ブランチ `main` / フォルダ `/ (root)` を設定します
   （他のアプリと共通のPages設定がすでにあれば、このステップは不要です）。
4. 保存すると数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/swiss7-tournament/` で公開されます。
   このURLは常に最新版を表示します（GitHub Pagesはpushのたびに自動更新されるため）。

## 4. 動作確認

1. 上記URLにアクセスし、「新しい大会を作成」フォームに大会名を入力して作成できることを確認します。
2. 「チーム登録」タブで7チーム分入力して保存できることを確認します。
3. 「1日目」タブで各試合の得点を入力・保存すると、勝った側がハイライトされ、順位表が更新されることを確認します。
4. 全7試合の結果が揃うと「2日目作成」バーが表示され、押すと2日目の対戦カードが自動生成されることを確認します。
5. 「2日目」タブでも同様に得点入力・順位確定ができることを確認します。
6. 各タブの「PDFダウンロード」を押し、数秒後に「PDF表示・ダウンロード」ボタンが表示され、クリックすると新規タブでPDFが開くことを確認します。
7. トップ画面の「大会一覧」から、作成済みの大会を再度開けることを確認します。

## トラブルシューティング

- **一覧が読み込めない/保存できない**: `GAS_API_URL` が正しいか、GASデプロイの「アクセスできるユーザー」が「全員」になっているかを確認してください。
- **大会作成でエラーになる**: テンプレートシート「１日目」「２日目」が削除・改名されていないか確認してください。
- **PDF作成でエラーになる**: `You do not have permission to call UrlFetchApp.fetch` というエラーが出る場合、承認したスコープにPDF出力に必要な権限が含まれていません。Apps Scriptエディタの左メニュー「プロジェクトの設定」→「"appsscript.json"マニフェスト ファイルをエディタで表示する」にチェックを入れ、`appsscript.json` を開いて `oauthScopes` に以下を追加してください（既存の行があれば残したまま追記）。
    ```json
    "oauthScopes": [
      "https://www.googleapis.com/auth/spreadsheets",
      "https://www.googleapis.com/auth/script.external_request"
    ]
    ```
    保存後、エディタ上部の関数選択で `exportPdf` 以外の適当な関数（例: `listTournaments`）を一度「実行」して新しい権限の承認ダイアログを通し、その後「デプロイ」→「デプロイを管理」→ 既存のデプロイを編集 →「新バージョン」で更新してください（URLは変わりません）。
  PDFはDriveに保存しない方式のため、Driveへのアクセス許可は不要です。
- **2日目作成でエラーになる**: 1日目の7試合すべての得点が入力されているか確認してください（順位（K列）が1つでも空だと実行できません）。
- **大会を削除したい**: トップ画面の大会一覧の「削除」ボタンから、1日目・2日目のシートごと削除できます（元に戻せないので注意してください）。
