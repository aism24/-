# tdf-dim-count 回帰テスト(正解値の固定)

`node tests/tdf-dim-count/run.js` で、`fixtures/` のTDFを `tdf-dim-count/core.js` で読み、`expected.json` の正解値と一致するか確認する(1件でも不一致なら終了コード1)。
`core.js` を変えたら、必ず実行して**正解値が悪化していない**ことを確認する。正解値を変えるのは、人が正解を確認したうえで `--update` を付けたときだけ。
※このフォルダはアプリ(`tdf-dim-count/`)の外にあるので、Vercelの本番デプロイには含まれない。
