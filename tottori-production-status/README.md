# 鳥取工場 生産状況(前日出来高・生産遅れリスト)

鳥取工場の「前日出来高」と「生産遅れリスト」を表示し、Excelでダウンロードできるウェブアプリ(iPad対応)。
データの元は、生産管理ダッシュボード(`production-management/`)と同じ索引スプレッドシート「Excelマスタ一覧」と各案件マスター。

## 決まり(2026-11-11 ユーザー指定)
| 項目 | 決まり |
|---|---|
| 対象 | 案件マスターの「加工先」= 鳥取 の行だけ |
| 生産予定日 | 「備考①」列(I列)に日付が入っている行のその日付 |
| 生産日 | 「加工」列(X列)の日付(生産管理ダッシュボードと同じ) |
| 前日出来高 | 加工 = 前の営業日(会社カレンダー=索引のI・J列の「出勤」日)。月曜なら直前の出勤日 |
| 生産遅れリスト | 備考①が今日より前、かつ 加工 に日付が無い行 |
| 遅れ日数 | 今日 − 生産予定日(暦日) |

列は見出しの文字(加工先・製品マーク・図番・重量・備考①・加工)で探すので、列の位置がずれても動く。
会社カレンダーに無い日に当たったときは、土日を休みとみなして前の営業日を決め、画面に注意を出す(カレンダーを延ばす合図)。

## ファイル
- `index.html` / `app.js` / `style.css`: 画面(静的ページ)。ExcelはブラウザでExcelJSを使って作る
- `sample.json`: GASのURLが未設定のとき(または `?demo=1`)に出すサンプル(実データではない)
- `gas/Code.gs`: GAS(新しいスプレッドシート「鳥取工場生産状況周知」に紐づけて使う)
- `gas/appsscript.json`: GASの設定の参考(時間帯 Asia/Tokyo・Drive API v3)
- `to-launcher.js`: 「← アプリ一覧へ」ボタン(正本は `docs/to-launcher/`)
- `vercel.json`: push・マージでVercelのビルドを走らせない

## 仕組み
1. GASが毎朝6時ごろ、索引の案件一覧(A〜E列)を見て、**更新日時が変わった案件マスターだけ**読む。
   Excelは一時的にスプレッドシートへ変換して読み、読み終えたらすぐ削除する(元のExcelには触れない)。
   生産管理ダッシュボードが作る `_作業用_…` は使わない(ファイル名が最初に変換したときの工事名のまま変わらず、索引の行と確実に結び付けられないため)。
2. 鳥取の行のうち、備考①か加工に日付がある行だけを「取込データ」シート(非表示)に保存する。
3. 前日出来高・遅れリストを作って、それぞれのシートへ書く。画面はGASの `doGet` からJSONで受け取る。
4. 画面を開いた日が「基準日」と違えば(朝の更新の前など)、取込データから一覧だけ作り直す(案件マスターは読まない)。
5. 1回の実行は240秒まで。読み切れなかった案件は1分後に自動で続きを読む(初回の取り込みなど)。

## シート
| シート | 中身 |
|---|---|
| 情報 | A列=項目、B列=値。`索引スプレッドシート`(URLかIDを貼る)・`対象拠点`(鳥取)・基準日・前の営業日・最終更新・未取込の案件・注意 |
| 前日出来高 | 工事名・製品名・図番・重量(t)・生産日 |
| 遅れリスト | 工事名・製品名・図番・重量(t)・生産予定日・遅れ日数(遅れ日数の大きい順) |
| 取込データ(非表示) | 案件ごとの鳥取の行 |
| 状態(非表示) | 案件ごとの元ファイル更新日時・取込日時・行数・エラー |
| 利用記録(非表示) | 起動・ダウンロード(画面には記録したことを出さない) |

## セットアップ(初回だけ)
1. スプレッドシート「鳥取工場生産状況周知」を開き、「拡張機能 → Apps Script」。
2. `gas/Code.gs` の全文を貼って保存。左の「サービス」の＋から **Drive API(v3)** を追加。
3. `setupSheets` を実行(初回は権限の承認が出る)。シートと見出し、毎朝6時ごろの自動更新ができる。
4. 「情報」シートの `索引スプレッドシート` の値に、「Excelマスタ一覧」のURLを貼る。
5. `refreshNow` を実行(初回は全案件を読むので数分。読み切れない分は1分後に自動で続く)。
6. 「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」。次のユーザーとして実行=自分、アクセスできるユーザー=全員。
   GASを使うアプリは mst アカウントで作成・デプロイする(`docs/know-how.md`)。そのアカウントが案件マスターを読めること。
7. 表示されたウェブアプリのURLを、`app.js` の `GAS_URL` に入れる(Claudeに伝えれば反映する)。

GASを直したら `CODE_VERSION` を上げ、「デプロイを管理 → 編集 → 新バージョン」。反映は `?action=ping` の版で確認する。
