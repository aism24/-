# 継手基準図からSPLシート作成(spl-sheet-web)

入力データー(○○).xlsm の「SPL」シートを、継手基準図(J-01〜J-12 などの .tdf)から作る・最新図と照合する Web アプリ。
2026-11-17 作成。前身はローカルの Python 版(社内の共有フォルダに置いた Tkinter アプリ。読み取りと突き合わせの決まりは同じ)。

## 使い方
1. **① 工事名をリストから選び(設定シートの工事一覧)、Excelを取り込む** … 入力データーの .xlsm を選ぶ(ドロップも可)。工事が未選択なら Excel の工事番号(「ﾃﾞｰﾀ」シート E1・F1)の工事を自動で選ぶ。選んだ工事と Excel の工事番号が違えばポップアップで確認。記録と「前回のフォルダ」は選んだ工事で行う(2026-11-17 ユーザー指示)。
2. **② サーバーのボタンを押して、図面のあるフォルダを指定し、ファイルを選んで抽出**(2026-11-17 ユーザー指示: 広く探さず、ファイルのあるフォルダを指定して、その中のファイルを選ぶ)
   - フォルダ内の .tdf を一覧にし、名前に「継手基準図」を含むものに最初から印。選んだファイルだけ読む。
   - 先にファイルのあるフォルダを指定。図面の場所(リンク・実寸法師で開く用)が分からないとき(初回)だけ、そのフォルダから始まる選択画面で上の階層の「①進行中工事」を選んで覚える(中は探さない。指定フォルダが中にあること・工事フォルダの1つ上であること・目印ファイルで確認)。選ばなければリンク無しで進める。
     場所は `①進行中工事.resolve(指定フォルダ)` の道筋と、設定シートのサーバーのパスをつないで作る。
   - 工事ごとに前回のフォルダを覚え、次回は「このフォルダを使う」で選べる。
   - フォルダ選択の id は英数字だけ(日本語のサーバー名を入れると showDirectoryPicker がエラーになった)。
   - 最新図と違いがあればポップアップで一覧を出す。
3. **表で直す** … セルをダブルクリックで編集。図番・継手名のクリックで実寸法師が開く(`jissun://` 独自プロトコル。PowerShell の Start-Process で開く。各PCで登録用の .reg を1回実行しておく)。
   「選んだ行を図面の値にする」「違いを全部図面の値にする」。丁番(T)・ボルト(V)は比べない・変えない。
4. **③ Excelに保存** … 取り込んだ .xlsm の SPL シートを表の内容にして、`元の名前_SPL作成_日時.xlsm` でダウンロード。

## 図面の読み方(spl-core.js)
- 継手名 = 図面の中でいちばん大きい英数字の文字。名前1つを1区画とし、区画の大きさは名前の並びの間隔で決める。
- 「FLG」の行の SPL → Fr外、その下 → Fr内、「WEB」の行 → Web。枚数はフランジ=図の数字×2、Web=図の数字。
- `2fill.PL-1.6x…` → フィラー「PL1.6」。SPL がある継手は U「有」。GPL だけの継手は継手名だけの行。
- .tdf の文字の読み方は tdf-master-web/scripts/tdf_binary.py の `_parse_texts` と同じ(文字だけ使うので JavaScript に移した。Pyodide は使わない)。

## 突き合わせ
- 1回目は図番と継手名が両方合う行どうし、2回目は残りを継手名だけで組にする(同じ名前は上から順)。
- 図面に無い Excel の行は「手入力」としてそのまま残す。図面にだけある継手は、図面の順で直前の継手の行の後ろに追加。
- フィラー列のメモ書き(「PL6取付」等)は比べない。Excel の図番が空なら図面の図番を入れる。

## Excel の書き方(xlsm-spl.js)
- JSZip で sheet XML を直接書き換える(マクロ・他のシートは触らない)。4行目から下を表の順に全部書き直す。
- 書式は書き込む行に元からあるセルの書式。C・D・I・N の式は元の式の行番号だけ変えて全行に入れ、calcChain を消して開いたときに全部計算させる。
- 図番・継手名に `file:///` のハイパーリンク(元の書式+青の下線)。前に付けたリンクは外してから付け直す。

## GAS(gas/Code.gs)とスプレッドシート
管理用スプレッドシート「SPLシート作成」にバインド。`setupSpreadsheet` を1回実行してからウェブアプリとしてデプロイ(実行=自分、アクセス=全員)し、URL を app.js の `GAS_API_URL` に入れる。
- 設定: 1行目の見出し「工事番号」「工事名」「サーバー」「ファイルパス」で列を探す(今は A・B と E・F。サーバーのパスはリポジトリに書かない。ここから読む)
- 記録: 保存のたびに1行。保存した表の中身は `yyyyMMdd_HHmmss_工事番号` のシート(新しい10枚だけ)。
- 利用記録: アプリを開いた日時。記録は画面に出さない。
